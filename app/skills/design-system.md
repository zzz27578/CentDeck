# 技能：配色与按钮样式

目标：给当前网站出几套可以直接应用的设计规范（tokens）。

1. 每套都给出 `colors`（brand、brandDeep、accent、bg、text、muted、card、border）、`fontSizes`（6 级，从小到大）、`spacing`（5 级）、`radius`（3 级，第一级是按钮圆角）。
2. 文字和背景的对比度要够（正文至少 4.5:1），主按钮上的文字要清楚。
3. 每套用一句话说明感觉，例如"安静专业""年轻活泼"，并说明主按钮是什么形状（方角 / 圆角 / 胶囊）。
4. 输出格式和 `design/tokens.json` 一样，用户在"设计规范"面板导入后点"应用到全站"即可生效。
5. 不要直接改页面里的颜色值；统一改 `cd-tokens` 里的变量。
