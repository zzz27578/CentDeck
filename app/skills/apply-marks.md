# 技能：按草图标记修改

目标：按用户在页面上画的草图标记（编号 #1、#2……）和写下的要求，逐条修改代码。

1. 每条标记都带了页面、元素、代码行号和相关片段；先按行号找到代码，再动手。
2. 只改和这条标记有关的地方，其它代码一个字都不要动。
3. "想挪到新位置"的箭头：用合适的排版方式实现（调整顺序、flex / grid、间距），不要用绝对定位硬塞。
4. "参考图"：把 `assets/` 里对应的图片放进页面，大小和位置参考标记；需要的话给出合适的 `alt` 文字。
5. 用户只画了图没写字的，按图意理解；拿不准的，做完后在回复里说明你的理解。
6. 完成后按编号逐条汇报：#编号 → 改了哪个文件第几行，一句话说明。
