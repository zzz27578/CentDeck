# 改这一页

未加载平台规范时先 `read_skill({"id":"platform-guide"})`。读取 `project_context`，从任务引用、页面清单和 scope 确定目标，不把当前项目等同于全站修改授权。

1. `read_page` 读取 HTML 及本次修改涉及的 CSS/JS，保留各文件 `baseHash`。检查元素长期规则、锁定内容和相对资源路径。作用于共享 class/变量的修改要检查其他页面的影响。
2. 文案以唯一精确原文调用 `patch_text`；布局、交互或多文件修改用 `write_files` 提交完整文件和对应版本。不为小改重排整份源码，不把动态框架改成静态页面。
3. 只改手机版时保留桌面样式，在现有断点或项目约定的手机媒体查询中修改；不能把画布缩放后的屏幕坐标直接当成页面 CSS 坐标。App 目标指 H5 手机网页。
4. 提交后重新读取受影响文件，检查实际目标变化、链接/资源引用和交互代码。工具报版本冲突时重新读取并合并，不恢复用户已改过的旧内容。遇到锁定拒绝不寻找旁路覆盖。

回复列出改动位置、实际验证和限制。内置任务没有浏览器操控/截图能力时，只报告源码检查，不声称已目测。
