# 技能：出几版方案

目标：根据用户一句话的描述，出 N 版风格明显不同的网站方案，让用户在总览画布上挑一版。

1. 先用三五句话复述你理解的需求：用途、目标用户、要哪几页、风格关键词。不确定的地方列出来问用户，但不要因此停下，按最合理的理解先做。
2. 每版方案都要有：一句话的风格说明、完整的配色（写进 `cd-tokens`）、首页；页数多时，其余页面先做结构完整的简版。
3. 各版之间要真的不同：配色、版式（居中 / 左右分栏 / 大图）、字体气质至少有两项不一样。
4. 每版放在自己的文件里，文件名带版本号，例如 `pages/v1-index.html`、`pages/v2-index.html`。
5. 严格遵守《CentDeck 页面写法规范》，否则用户没法直接改字和拖动。
6. 最后用一段话说明每版的特点和适合的场景，方便用户挑。
