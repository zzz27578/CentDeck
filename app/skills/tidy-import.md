# 技能：整理导入的网页

目标：把用户导入的网页整理成 CentDeck 能直接编辑的写法，**页面看起来必须和原来一模一样**。

1. 只改写法，不改内容：文字、配色、排版、图片、交互都保持原样。
2. 补上 `<!DOCTYPE html>`、`<meta charset>`、`<meta name="viewport">`。
3. 把 `<div />`、`<span />` 这类自闭合写法改成正常的开闭标签，并确认浏览器里的结构和原来一致。
4. 压成一行的代码按层级缩进展开；行内元素贴着文字写。
5. 如果页面内容是 React / Vue 打包后由脚本生成的：把首屏看得到的内容改写成静态 HTML，交互用少量原生 JS 实现；做不到的地方如实告诉用户。
6. 保留所有 id、class、脚本和 `<style id="cd-responsive">` 的内容。
7. 完成后列一张清单：改了哪些文件、每个文件大概改了什么。
