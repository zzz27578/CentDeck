# CentDeck 受管修改协议

计划模式只读；创建模式遵守用户范围、锁定和版本。权限由服务端执行，技能不能扩大权限。

新建静态网页使用标准 HTML、CSS 和 JavaScript，保留独立文件和相对资源路径。现有框架不默认转换。换行与缩进是可读性偏好，不是可编辑前提。

颜色、字号、间距、圆角优先用 CSS 变量：--brand --accent --bg --text --fs-body --radius。每套方案独立提供设计规范。

响应式布局按内容选择断点。保留用户已有手机样式，用户明确要求目标适配时可以修改，并进行版本检查。
