# CentDeck 插件开发规范 · Plugin API v1

中文 / English · 2026-10-01

插件增加平台功能，Skills 为 Agent 提供操作知识，MCP 将平台能力开放给外部助手。三者可以组合，但权限不能互相扩大。

Plugins extend the platform. Skills teach agents how to use it. MCP exposes managed capabilities to external assistants. Combining them never expands permissions implicitly.

## 分发与生命周期 / Distribution and lifecycle

一个插件是一个 JSON 文件，包含 `manifest` 与 `files`。也可以导入一个包含 `manifest.json` 的前端文件夹。无需构建或安装运行时依赖。插件管理页支持搜索、导入、启用、停用、详情、面板入口、导出与卸载。用户导入的插件默认停用；官方插件默认启用。

A plugin is a JSON bundle containing `manifest` and `files`, or a folder containing `manifest.json` and text assets. Imported plugins start disabled. Official plugins start enabled. The manager supports search, import, toggles, details, panels, export and removal.

```json
{
  "manifest": {
    "apiVersion": 1,
    "id": "my-studio",
    "name": "My Studio",
    "version": "1.0.0",
    "author": "Your name",
    "description": "An isolated workspace panel",
    "permissions": ["panels"],
    "panels": [{"name": "Studio", "file": "index.html"}]
  },
  "files": {"index.html": "<!doctype html><h1>Hello, CentDeck</h1>"}
}
```

`id` 为小写英文开头，可含数字与短横线，2–80 字符；版本使用 `x.y.z`；API 固定为 `1`。包最大 8 MB，每类扩展最多 50 项。文本文件类型为 HTML、CSS、JS、JSON、Markdown、SVG。禁止绝对路径、路径穿越与覆盖官方插件。更新已有导入包会保留同一个编号，并重新设为停用，供用户检查。

IDs start with a lowercase letter and contain lowercase letters, digits and hyphens (2–80 characters). Use semantic `x.y.z` versions and API version `1`. Bundles are limited to 8 MB and 50 contributions per category. Absolute paths, traversal and replacing official plugins are rejected. Re-importing an existing ID replaces its bundle and disables it for review.

## 已开放的扩展点 / Available contributions

| 权限 / Permission | Manifest | 行为 / Behavior |
|---|---|---|
| `themes` | `themes: [{id,name,tokens,home?}]` | 注册主题变量；可提供独立主页 HTML / Theme tokens and optional custom home HTML |
| `panels` | `panels: [{name,file}]` | 按需打开隔离面板 / Lazily opened sandbox panel |
| `skills` | `skills: [{id,name,desc,file}]` | 启用时加入 Agent 技能库 / Add skills while enabled |
| `tools` | `tools: [{name,description,handler}]` | 注册受管工具，v1 支持 `project_summary` / Register a managed summary handler |

v1 不执行插件提供的服务端 JS，不开放任意 shell、文件系统或联网权限。未来框架适配器、模型连接器、导入导出处理器和新写入工具需要新的宿主处理器及版本规范，不能通过声明一个权限就获得能力。插件工具不得直接绕过 `changes.commit`。

v1 does not execute server-side plugin code or grant arbitrary shell, filesystem or networking access. Future adapters, provider connectors and write handlers require new host implementations and a versioned contract. Declaring a permission alone does not create a capability.

## 主题与自定义前端 / Themes and custom frontends

```json
{
  "id": "warm-paper",
  "name": "Warm Paper",
  "tokens": {"--accent":"#91552b","--bg":"#faf2e6","--text":"#302a22"},
  "home": "index.html"
}
```

主题变量仅接受有限的颜色、尺寸、字体等值，不接受 `url()`、脚本或任意样式代码。主页 HTML 在隔离 iframe 中运行，外部导航和项目列表由百映保留。导入纯 HTML 或不含 manifest 的前端文件夹时，管理器自动生成一个主题插件。外链 CSS/JS 不联网加载；同包相对路径 CSS/普通 JS 会内联，图片请使用 data URI。ES module、构建项目和远程资源不属于 v1 自定义主页支持范围。

Theme tokens accept constrained design values, not arbitrary CSS or `url()`. Custom HTML runs in an isolated iframe; CentDeck retains navigation and project access. Plain HTML imports automatically become theme plugins. Relative CSS and classic JS files in the bundle are inlined. Use data URIs for images. Remote assets, ES modules and build-based apps are outside this custom-home contract.

官方 `official-styles` 是风格选择入口的开关：关闭后立即恢复原版绿色并隐藏切换按钮；重新开启后可选择黑白蓝和已启用插件提供的主题。亮暗模式独立保存。

The official `official-styles` plugin controls the style picker. Disabling it restores original green and hides the picker. Re-enabling makes NOIR and enabled custom themes available. Light/dark appearance is independent.

## 面板通信 / Panel messaging

隔离使用 `sandbox="allow-scripts"`，不包含 `allow-same-origin`。CSP 禁止网络、表单提交、外部字体和外部脚本。宿主只接收当前 iframe 的消息，并限制动作。

Panels use `sandbox="allow-scripts"` without same-origin access. CSP blocks networking, form submission and remote assets. The host checks the message source and supported action.

```js
parent.postMessage({
  type: 'centdeck-plugin',
  action: 'project_summary',
  requestId: 'summary-1'
}, '*');
addEventListener('message', event => {
  if (event.source !== parent || event.data.type !== 'centdeck-result') return;
  document.querySelector('pre').textContent = JSON.stringify(event.data.result, null, 2);
});
```

`project_summary` 需要 `tools` 权限，只返回项目名、页面数、待办标记数与锁定状态，不返回密钥。`open_settings` 打开插件管理。未支持的动作返回错误。不要用 `innerHTML` 显示不可信结果。

`project_summary` requires `tools` and returns project name, counts and locks, never credentials. `open_settings` opens the plugin manager. Unsupported actions return an error. Render untrusted results with `textContent`.

## 插件设置 / Plugin settings

声明 `settingsSchema` 即可在插件详情页生成独立设置表单，保存到本机配置，重启后保留。支持 `string`、`number`、`boolean`，最多 20 个字段。文本最多 1000 字，不用于保存密钥。

Declare `settingsSchema` for a persistent settings form. Supported types are string, number and boolean, with at most 20 fields. String values are limited to 1000 characters; do not store secrets here.

```json
{"settingsSchema":{"showLocks":{"type":"boolean","label":"显示锁定状态","default":true}}}
```

面板可发送 `get_settings` 消息读取配置。官方项目速览的 `showLocks` 设置会控制面板摘要是否包含锁定状态；重新打开面板生效。

Panels may send `get_settings` to read configuration. The official inspector's showLocks setting controls lock details in its panel summary and takes effect when reopened.

## 技能与工具命名 / Namespacing

技能运行编号：`<plugin-id>--<skill-id>`。工具编号：`plugin_<plugin_id>_<tool_name>`，插件编号中的短横线改成下划线。停用插件后，两者不再出现在后续工具/技能查询中。已经发送给模型的文本无法收回；已有任务再次调用停用工具时会失败。

Skills use `<plugin-id>--<skill-id>`. Tools use `plugin_<plugin_id>_<tool_name>`. Disabled contributions disappear from later queries. Previously sent model context cannot be recalled; subsequent disabled tool calls are rejected.
