## 实际操作证据

使用 MCP 客户端发送真实 `initialize` / `tools/call`，并由浏览器心跳通道返回操作结果：

1. `ui_state` 发现登录后的工作台。
2. `ui_action open_settings` 打开插件管理；实际截图检查。
3. 启停官方风格插件，验证按钮隐藏、绿色恢复与再次启用。实际通过文件选择器导入暖纸 JSON 插件，验证默认停用、开启后加入风格列表，并通过 MCP 点击切换到自定义沙箱主页。
4. 打开项目与页面，添加便签型草图。服务端读取标记数为 1；撤销后为 0。
5. `start_agent` 启动内置 Agent，使用隔离测试提供商完成一次方案生成；返回 `think: high`，加载 `platform-guide` 与 `design-variants`，存在 1 次提交。
6. 主项目服务：通过 `read_page` + `write_files` 原子写入“余白 YUBAI”4 个真实文件；项目编号 `yubai-mcp`。
7. 余白桌面、393px 手机检查；手机文档宽度与视口一致，没有横向溢出；作品筛选从 2 项变为 1 项；咨询弹窗和本地表单摘要正常；案例跳转正常。

## 真实模型联调限制

当前本机已有提供商的模型发现返回 **HTTP 401**，未配置可选模型 ID。已向用户说明需要修正提供商配置。隔离测试提供商是可控测试桩，其成功只证明任务和工具链工作，不证明真实模型服务可用。

因此，真实模型联网生成验收仍未完成。没有测试 Codex/Claude Code/DeepSeek Harness 的各自客户端；只验证本项目标准 MCP 客户端协议与页面控制链。不应声称完整路线图或所有客户端已验收。

## English acceptance summary

The double-click local workflow is unchanged. The extension host, plugin manager, default style plugin, Skills management, shared tools, MCP transport/browser bridge, settings, login refinements and source ZIP export are implemented. A new two-page YUBAI frontend was committed through MCP and exercised on desktop/mobile.

Automated regression suites passed. A real MCP client controlled the browser, added and undid a persisted mark, and started a built-in agent using an isolated test provider. That task returned the requested reasoning level and a real file commit.

The user's configured real provider returned HTTP 401 during model discovery, so real-provider generation is not accepted as complete. No other AI client was tested. Wider roadmap items such as framework adapters, timelines and automatic deployment remain unimplemented; the v1 plugin host is a foundation for those extensions.
