# 对话归档、上下文与模型配置调整

本轮按新的交互要求修订上一轮的对话分支、上下文展示和提供商表单。此前报告里的“编辑另开分支”和“最近 12 条消息”已由下面的行为替代。

## 一段对话的边界

- 编辑历史消息、重新生成和错误重试均沿用当前 conversationId，替换所选消息之后的内容；不会新增历史条目。
- 被替换的内容保留在该会话的 revisions 中。旧任务 ID 被排除，迟到结果及刷新不会把旧回复再次插回来。
- 请求失败时恢复原消息，保留编辑草稿供再次尝试。已保存的网页修改不因编辑聊天而自动回滚。
- 新对话、新窗口和各助手的独立聊天分别保存。没有正式消息的窗口保存为草稿，不属于对话历史；输入草稿仍可在刷新后恢复。
- 对旧版分支，只在同一助手的记录共享真实消息 ID 时归并；不按标题或相似文本合并，避免误合并独立聊天。旧版本保留，活动窗口指向归并后的记录。
- 对现有测试数据做了只读迁移演练：8 项旧记录整理为 1 段正式对话、3 份草稿，4 个旧版本保留备份。实际迁移在更新后的页面加载项目时执行，并随项目元数据保存。
- 历史页面按项目折叠分组，支持查询、继续对话、独立窗口、重命名及删除。时间显示到小时和分钟。项目菜单提供当前项目分组和“全部项目的对话历史”入口。

## 消息与上下文

- 用户消息的复制和编辑操作与消息右边缘对齐。
- 上下文入口为会话标题行的小圆环，不增加输入区行高。悬停、聚焦或点击后显示用量，使用整数或 K 格式。
- 接口提供 prompt/completion token 数据时显示实际用量；否则显示估算。容量来自模型设置或模型列表元数据；未知容量显示虚线环，不伪造占用比例。
- 支持 `/compact` 和浮层中的“压缩上下文”。较早消息经一次无工具模型请求生成摘要，保留较新的消息；可滚动查看的原聊天不删除。后续请求实际使用摘要。内容很短时无需请求模型；摘要变长、截断或失败时保留原上下文。
- 普通对话不再静默裁成最近 12 条；保留完整历史或已生成的摘要。按配置的模型窗口检查输入并限制输出长度。
- 错误用红色文字显示，失败操作只保留重试图标，悬停显示“重新尝试”。必要的暂停恢复仍由运行层保留。
- 助手选择中，当前助手使用强调背景和“当前助手”文字。

## 提供商与模型

- 参照提供的截图，改为左侧提供商源列表、右侧连接设置与模型列表。删除连接位于左侧对应条目。
- 移除底部保存、清除密钥和删除连接栏。保存配置位于右上角，保存后显示“已保存”并留在当前页面。
- API Key 保留小眼睛，默认遮蔽，已保存的密钥不回传；继续关闭自动填充并保护 MCP 私密字段。
- 模型行显示能力徽标，右侧提供启用开关、单次测试、齿轮设置和删除。
- 齿轮中配置文本、图像、音频、工具使用、上下文窗口大小及 JSON 请求体参数。
- 连接高级设置支持超时时间及 JSON 请求头；模型级请求参数会用于实际请求。请求结构、工具和流式字段不允许被覆盖，输出仍受运行层上限约束。OpenAI Compatible 的显式 reasoning_effort 参数优先于聊天中的档位。
- 获取模型列表与测试模型分开。单模型测试只发送一条最小推理请求，不附带 Skills、历史或工具，不发现其他模型，不自动重试或切换接口。前端禁用重复点击，后端拒绝同一连接/模型的并发测试。
- 模型测试用于验证接口响应，不声称已验证图片、音频或工具能力。

## 验证

使用隔离项目、临时配置、独立 Chromium 和本机模拟模型接口，没有消耗用户外部 API 额度，也没有直接改写正在打开的用户项目或提供商配置。

- 浏览器：原位编辑/重试、空历史排除、项目分组、归档删除/刷新、右侧按钮对齐、320 px 助手栏、圆环浮层、真实摘要请求与后续摘要使用。
- 浏览器：红色错误、只含图标的重试、配置保存后不离页、齿轮弹窗、上下文容量保存、密钥显示切换、双击测试仍只有一次请求。
- 服务端：测试成功与失败均一次请求、并发测试拒绝、OpenAI/Gemini 两种测试格式、旧密钥复用、自定义参数/请求头持久化与实际传递、摘要截断保护。
- 原有 Agent 26 组集成、提供商、MCP、外部运行层、Skills、工作台交互和 65 个前端模块语法检查通过。

主要测试为 `tests/conversations-browser.test.mjs`、`tests/conversations.test.mjs`、`tests/provider-options.test.mjs`。截图位于 `docs/screenshots/` 的 `provider-editor-*`、`model-settings-light.png`、`conversation-history-light.png` 和 `chat-context-usage.png`。

需要重启百映服务并刷新页面以同时加载新后端与前端。新模型测试仅在用户点击时发出请求；上下文压缩使用当前选定的模型接口，可能产生对应的模型用量。
