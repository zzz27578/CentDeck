# CentDeck · 百映

> **AI 负责写网页，你负责指和改。**

CentDeck（百映）是一个给不会写代码的人用的 AI 网页工作台。AI 做出来的网页会完整摊开在一块画布上；哪里不对，点一下、圈一下就能指给 AI。改个字、对个齐这种小事，像做 PPT 一样自己动手，改完直接存进代码，不花 AI 额度。

名字由来：Cent（百）+ Deck（一叠页面）——百页尽映，是为"百映"。

## 它帮你做到四件事

- **看得见**：所有页面、弹窗、跳转关系摊在无限画布上，像 PPT 一样真实放映。
- **指得准**：点选、圈选、@，把"右边那个按钮"精确定位到代码行，不靠口述。
- **改得动**：改字、对齐、换字号自己动手；每次修改亮一盏"三灯"——绿灯直接写回、黄灯提示连带影响、红灯恢复原样并转成 AI 任务。
- **花得省**：能手动的不花 token；需要 AI 时按任务大小自动分档，贵模型出设计，便宜模型施工。

## 快速开始

环境要求：Node.js 18 及以上（本机开发使用 v24）。

1. **启动**：双击 `CentDeck.bat`（Windows），或命令行执行 `node server/server.js`（macOS / Linux 可用 `bash start.sh`）。启动后自动打开浏览器，默认地址 `http://localhost:8420`（端口被占用会自动后移，也可用 `PORT` 环境变量指定）。
2. **使用**：在首页选择内置模板一键创建项目 → 总览画布查看页面关系 → 进入编辑、草图或放映。
3. **退出**：在启动的终端窗口里输入 `exit` 或 `q` 回车，或直接 Ctrl+C，即停止监听。
4. **一键还原**：工作台内的红色"一键还原"按钮，把项目恢复到模板初始状态（清除全部改动、标记、便签和历史，需二次确认）。

你创建的项目保存在 `projects/` 目录，一个项目就是一个普通文件夹，可打包带走、可用 Git 管理。

## 操作速查

| 想做什么 | 怎么做 |
|---|---|
| 切换视图 | 顶部"总览 / 编辑 / 放映"，或 Alt+1、Alt+2、F5（像 PPT 一样放映） |
| 选中、拖动 | 选择工具（V）：点一下选中，按住直接拖；Shift+Enter 选外面一层，Tab 选下一个 |
| 缩放元素 | 拖选中框的角点 = 等比缩放；拖边线 = 改宽 / 高 |
| 微调位置 | 方向键 1 像素，Shift+方向键 10 像素 |
| 改字 | 双击文字，或文字工具（T）点进去；回车确认，Esc 取消 |
| 像访客一样点页面 | 交互工具（I）：按钮、弹窗、表单、跳转都是真的 |
| 画草图 | P 画笔、A 箭头、R 方框、O 圆圈、N 便签钉、G 虚影、E 橡皮 |
| 缩放画面 | Ctrl+滚轮；Shift+1 适应屏幕；Ctrl+0 实际大小；空格+拖动平移 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z（改代码、画标记、锁定都能撤） |
| 召唤助手 | Ctrl+K |
| 全部快捷键 | 按 ?（Shift+/） |

## 技术形态（已确认）

一个监听本机端口的本地服务：双击启动 → 自动在浏览器打开工作台 → 开始使用；不用时在终端里退出，即停止监听。不做桌面套壳和安装包签名；Docker 部署列为第三步适配项（当前以本机运行为准）。

界面目前是原生 JavaScript 模块，零依赖、不需要构建（是否迁移到 TypeScript / React 待讨论）。项目就是一个普通文件夹：Git 可管，外部 AI（Claude Code、Codex 等）可通过本地服务提供的 MCP 接口直接接管编辑。
